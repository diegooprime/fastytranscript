# FastyTranscript

Raycast extension that fetches YouTube transcripts.

## Demo

https://x.com/diegooprime/status/1997911884528333044?s=20

## Usage

1. Copy YouTube URL
2. Run **FastyTranscript** in Raycast
3. Transcript auto-copied to clipboard

## How It Works

The Raycast command uses `yt-dlp` in two stages:

1. Direct subtitle download
2. Metadata fallback that resolves a subtitle URL and parses the result

The standalone CLI in [`cli.mjs`](./cli.mjs) also includes Android InnerTube and page-scraping strategies for comparison and troubleshooting.

Both paths require [yt-dlp](https://github.com/yt-dlp/yt-dlp) to be installed locally.

## Output

```markdown
# Video Title

**URL:** https://youtube.com/watch?v=VIDEO_ID

---

Transcript text...

---

_Generated by FastyTranscript_
```

## Manual Install

```bash
git clone https://github.com/diegooprime/fastytranscript.git
cd fastytranscript && npm install && npm run dev
```
